# PROBE: the two lazy boot-time decodes stay lazy (splash flip variants + AwardmentBlade).
#
# PINS: card 57555583. Two loads were made LAZY/DEFERRED because no warm queue can reach them
# (they run from a component's LoadContent, before Game1.LoadContent builds the queues):
#   1. SplashScene decoded all THREE channel-flip reveals and used ONE. It now rolls the variant
#      in LoadContent and decodes only the winner.
#   2. AwardmentBlade decoded its sheet + font at boot for a banner that only appears when an
#      awardment pops. Its load is lazy now, warmed by Game1.QueueIdleWarm during the splash.
#
# FAILURE MEANS: a boot-time decode came back. Restoring the eager loads is a one-line edit in
# either file and breaks NOTHING -- the game looks and plays identically, it just spends longer
# on the black pre-splash screen every single boot, which is why this is a probe and not a
# screenshot. The quoted COLD line names the asset that regressed.
#
# ?splashvariant=revenged pins the roll: the two portrait reveals are a 5% branch each, so
# without it "the pure shot was not decoded" would pass 95% of the time on the BROKEN code.
#
# The `expect` lines are not decoration (probes README rule 1). `easplashredone` proves the run
# reached the splash load at all and that COLD reporting still works; the `-revenged \d` line
# proves the ONE variant a run needs is still loaded, so "no pure decode" cannot pass by loading
# no reveal at all; and the WARM manifest line proves the blade sheet is decoded by the idle warm
# rather than simply never loaded, which is the way this change could go wrong invisibly.
#
# That `\d` is the size field, and it is what makes the line SPECIFIC -- a bare `-revenged` also
# matches `-revenged-pure`, and a trailing space would not work either (eahl Trim()s the pattern).
#
# eahl: --flags "?loadlog&noattract&splashvariant=revenged"

# Boot + the whole splash sequence, then let the idle warm queue drain (one asset per tick).
step 400 nodraw
eval PreloadExport

expect \[loadprofile\] COLD decode in \(boot\): gfx/splash/easplashredone
expect \[loadprofile\] COLD decode in \(boot\): gfx/splash/uglysplash22-revenged \d

expect-not COLD decode in \(boot\): gfx/sprites/awardmentblade
expect-not COLD decode in \(boot\): gfx/splash/uglysplash22-revenged-pure

expect gfx/sprites/awardmentblade\|WARM
quit
