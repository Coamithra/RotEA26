# PROBE: the evil grinning face of death fires a whole volley, and only while it can be shot back at
#
# PINS:   card d8344c17's two fixes to EvilSkull, both of which fail SILENTLY -- no crash, no
#         console error, no metric, and nothing about a skull's appearance changes with either.
#         The report they came from ("sometimes shoots a massive series of bullets, rather than
#         the expected number") took an instrumented soak to attribute at all, so a regression
#         here would go unnoticed until someone played the game and felt it.
#
#         1. THE VOLLEY COUNTER IS PER LIFE. EvilSkull is pooled; `bulletsfired` was the one
#            piece of its state nothing reset, so a skull killed part-way through a volley handed
#            its count to the next skull out of the pool, whose volley then ended that many shots
#            early. Measured before the fix: 42 of 194 volleys (21.6%) opened part-way through.
#         2. A FADING SKULL DOES NOT SHOOT. The 2008 fire gate tested `fadeintimer.Active` and
#            not the fade OUT, so a skull kept firing through its whole 800 ms dissolve, by the
#            end of which Draw has ramped its alpha to zero -- bullets from a source the player
#            cannot SEE. (It is also un-rammable and invisible to the AI while fading, though
#            still shootable: Bullet.CollidesWith lists the type unconditionally.) Measured
#            before the fix: 41 such bullets, 6.1% of the level's skull bullets, including 7
#            volleys that STARTED after the skull was already invisible.
#
# WHY THE REARM LINE CARRIES ASSERTION 1: a carried counter is NOT visible in the shot stream.
# It makes a truncated volley look like the seamless continuation of the previous skull's, so
# per-line the shots read perfectly healthy -- an analysis that segmented volleys by shot index
# alone reported the BROKEN build as clean during this card. The rearm is the one moment the
# invariant is expressible on a single line: a fresh volley must open at fired=0.
#
# FAILURE MEANS:
#   * `rearm fired=` non-zero    -> the per-life reset in EvilSkull.Initialize is gone. Volley
#                                   length is random again.
#   * `fade=out shot_fired=True` -> the fire gate is back on `fadeintimer.Active` instead of
#                                   `Fading`. Bullets are coming out of something the player
#                                   cannot see.
#   * either `expect` missing    -> the run never reached a skull at all; the negatives above
#                                   are vacuous and prove nothing. Check the level booted.
#
# NOTE Inzane + a long soak is deliberate: the volley cap is (int)(4 * DifficultyModifier) and
# that modifier RAMPS with level time, so a short or low-tier run only ever sees short volleys
# and never exercises the interesting end of the range. `?seed=` keeps the world comparable.
#
# MUTATION-TESTED, both legs, each reverting one fix to its pre-card form:
#   * dropping `bulletsfired = 0` from Initialize        -> 42 `rearm fired=[1-9]` lines, red.
#   * `!(flag | Fading)` back to `!(flag | fadeintimer.Active)`, and the classic branch's
#     `if (!Fading)` back to unconditional                -> 41 `fade=out shot_fired=True`, red.
# Both positives were confirmed to still pass on the fixed build in the same runs.
#
# eahl: --flags "?level=Level3&aiplayer&invuln&noattract&difficulty=Inzane&seed=1&skullvolley"

# Settle past the intro fade and the first skull spawners, mark away that boot noise, THEN soak
# -- the evidence is everything printed AFTER the mark, so the long step has to follow it.
step 600 nodraw
mark
step 25000 nodraw

# --- POSITIVES: the run really did reach skulls that armed, fired and completed a volley.
# Without these three, every expect-not below passes on a run that never spawned one.
expect \[skull\] tag=\d+ (normal|classic) rearm fired=0 cap=\d+
expect \[skull\] tag=\d+ (normal|classic) shot=1/\d+ fade=none shot_fired=True
expect \[skull\] tag=\d+ (normal|classic) shot=(\d+)/\2 fade=none shot_fired=True

# --- 1. No volley opens with a count carried over from a previous life.
expect-not \[skull\] tag=\d+ (normal|classic) rearm fired=[1-9]

# --- 2. No bullet leaves a skull that is fading out, i.e. invisible and not collidable.
expect-not fade=out shot_fired=True

# --- Neither fix may let a volley run PAST its cap; that was never broken and must stay so.
# Two digits or more is the whole runaway range: the cap is (int)(4 * DifficultyModifier) and
# the modifier ceiling is 2.4, so a legitimate shot index never reaches 10.
expect-not shot=\d\d+/

quit
