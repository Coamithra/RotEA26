# `expect ... Demo1 preload:` above it would STILL match, because the scene's own
# PreloadGraphicalContent opens its own bracket and prints that line regardless. Only the
# (boot) guard catches that case. Measured: it is exactly how Demo3 hid its 12 gaps.

# Window: mark at frame 400 (boot + the idle warm queue have drained by then), the attract
# timeout fires at 20 s = frame 1200, and the soak runs to frame 5000 (~83 s of demo).
