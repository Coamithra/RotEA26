# THE TRAP, AND WHY THIS DRIVES THE MENU RATHER THAN ?level=InsaneBossI:
# a ?level= boot has no splash, so Game1's QueueIdleWarm assets drain into gameplay and are
# recorded as THAT LEVEL's cold decodes -- exactly 20 spurious gfx/game/space/* lines, measured

# carousel index 6 -> select -> difficulty -> select.
#

# Braineroids, Evil Aliens Classic, Paratrooper, Base Pressure, Crazy Game, Boss Train, ...),

# right 6` is a six-tick HOLD, not six presses, and moves the carousel once.

# The soak is 180 simulated seconds rather than preload_level2's 90, because the bosses arrive
# in SEQUENCE: the level is still making real progress at the 90s mark (measured with eval

# 90s run would stop short of the later bosses and never touch their share of those 82 entries.
# Measured clean over five runs at this length.
#
# The `expect` before the `expect-not` is not decoration -- it is what stops this probe passing
# vacuously. Without it, a carousel reorder that landed the run on a different challenge would
# sail through, because the assertion below only ever mentions InsaneBossI.
#
# ?unlockall so the challenge is selectable from a wiped save; ?invuln + ?aiplayer so the level
