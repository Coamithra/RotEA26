# PROBE: the Paratrooper challenge decodes no textures during gameplay.
#
# PINS: wwwroot/Content/preload/manifest.txt's Paratrooper section (49 entries, the third
# largest). Same silent failure mode as preload_level2: that file is pure DATA, so a dropped
# line produces no build error and no failing test -- only a stutter the next time somebody
# plays the level.
#
# FAILURE MEANS: an asset Paratrooper uses is no longer preloaded, so it is decoded during
# live gameplay = a visible stutter. The quoted line names it. Fix by restoring the manifest
# entry (or, if the asset is genuinely new, capture it -- see LoadProfiler's header for the
# eaPreloadExport / MERGE-never-overwrite flow).
#
# THE TRAP, AND WHY THIS DRIVES THE MENU RATHER THAN ?level=Paratrooper:
# a ?level= boot has no splash, so Game1's QueueIdleWarm assets drain into gameplay and are
# recorded as THAT LEVEL's cold decodes -- exactly 20 spurious gfx/game/space/* lines, measured
# identically on Level2, Paratrooper and InsaneBossI. A probe booted that way either fails
# always or needs a whitelist that would mask the real thing. So: main menu -> Challenges ->
# carousel index 3 -> select -> difficulty -> select.
#
# Paratrooper is the FOURTH challenge (MenuScene.cs: Space Dodge, Braineroids, Evil Aliens
# Classic, Paratrooper, ...), and the carousel opens on Space Dodge -- hence three rights, as
# three SEPARATE taps: `eval Press right 3` is a three-tick HOLD, not three presses, and moves
# the carousel once.
#
# The `expect` before the `expect-not` is not decoration -- it is what stops this probe passing
# vacuously. Without it, a carousel reorder that landed the run on a different challenge would
# sail through, because the assertion below only ever mentions Paratrooper.
#
# ?unlockall so the challenge is selectable from a wiped save; ?invuln + ?aiplayer so the level
# is actually PLAYED for 90 simulated seconds rather than sitting on a dead ship.
#
# eahl: --flags "?menu&noattract&loadlog&unlockall&invuln&aiplayer"

step 150 nodraw
eval Press down 1
step 10 nodraw
eval Press down 1
step 10 nodraw
eval Press down 1
step 10 nodraw
eval Press enter 1
step 90 nodraw

# Everything above is boot + main menu. The (boot) cold decodes there are a different
# population and a different card's business -- drop them so this window is Paratrooper's
# alone. Nothing here depends on how MANY of them there are.
mark

eval Press right 1
step 10 nodraw
eval Press right 1
step 10 nodraw
eval Press right 1
step 30 nodraw
eval Press enter 1
step 120 nodraw
eval Press enter 1
step 5400 nodraw

expect \[loadprofile\] Paratrooper preload:
expect-not COLD decode in Paratrooper
